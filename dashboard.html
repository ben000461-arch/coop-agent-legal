Agent

Your agent

What it is

A private AI assistant you text on Telegram. It helps with everyday work: emails, spreadsheets, notes, your calendar and small code changes.

What it can do

  • Save email drafts in Gmail. It never sends email and never reads your inbox.
  • Read your Google Calendar to answer questions. It never changes events.
  • Create and edit spreadsheets and text files, and keep notes.
  • Prepare code changes in the GitHub projects you choose, as a pull request, only after you say yes.

How it works

It shows you what it is about to do and waits for your yes before it changes anything. Everything it does is listed on the Logs page, and the Connections page shows which tools it used.

How your agent is linked to you

Your agent belongs to one Telegram chat, and this website login is tied to that same chat. That’s how you only ever see your own agent’s activity. Nobody else can open your chat or your logs.

Things you can say

  • “what’s on my calendar today?”
  • “draft an email to Sam about Friday”
  • “make a spreadsheet of my expenses”
  • “note buy milk”, then “show my notes”
  • “what pull requests are open?”

Just talk normally. If it isn’t sure what you mean, it asks instead of guessing. Before it changes anything, it shows you and waits for your yes.

Commands

/help
What the agent can do. Add a question, like /help what should I do next.
/connect google
Link Gmail drafts and your calendar.
/connect github
Link the code projects you choose.
/connections
See what’s connected.
/disconnect google
Remove a connection (also github).
/code in myapp, fix the crash in server.js
Ask for a code change. It shows you the change first.
/changes
List saved code changes you can still turn into a pull request.
/model
Choose which AI writes your code.
/instructions
Tell the agent about your business and how you like it to talk.

Good to know

  • It only saves email drafts. You send them yourself.
  • It only reads your calendar.
  • Code changes go onto a new branch as a pull request, and only after you say yes.
  • Pasted passwords and keys are refused, so don’t send them in the chat.
