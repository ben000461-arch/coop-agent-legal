A private AI assistant you text on Telegram.

co|op Agent helps small teams get everyday work done by text message: drafting emails, keeping spreadsheets and notes, checking a calendar, and making small, reviewed code changes. It always shows you what it is about to do and waits for your yes before it changes anything.

  • Gmail: it can save drafts. It never sends email and never reads your inbox.
  • Google Calendar: it can read your events to answer questions, and add an event only after you say yes. It never changes or deletes events you already have.
  • GitHub: it opens pull requests only after you approve, and never changes your main branch.
